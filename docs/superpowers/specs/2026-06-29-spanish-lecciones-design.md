# Spanish "Lecciones": Design Spec

Date: 2026-06-29
Project: Pebble (`pebble-app.html` + embedded `veo-y-digo-source.html`)
Status: Approved design, ready for implementation plan

## Goal

Add structured Spanish teaching to the Español section. Gabby knows some words but not
sentence structure or the grammar rules. She wants lessons that actually teach (not just
vocabulary drills), a clear "road to fluency" checklist, a daily lesson she can take, the
ability to type "teach me future tense" / "teach me conjugations," and Duolingo-style
practice questions. She also wants to hear each word and sentence read aloud and save words
or phrases to a flashcard mix to study later.

## Approach: hybrid (fixed roadmap + AI-generated lessons)

The topic list is a fixed, ordered spine baked into the app. The teaching content and
practice questions for each topic are generated on demand by Claude using Gabby's
device-local API key, then cached on the device so the lesson is instant on later visits and
does not re-spend the API. The same generator powers a free-form "teach me X" command in the
existing Spanish chat.

This was chosen over a pure AI tutor (no structure, no daily path) and over a fully
hand-authored course (static, and every lesson would have to be written up front). The hybrid
gives structure and a progress path while keeping the content rich and low-maintenance.

## Where it lives

1. A new **Lecciones** screen inside the embedded Español app (`veo-y-digo-source.html`),
   alongside the existing Tarjetas, Oz, Diario, and Atajos screens. Added to the `screens`
   array and reachable from the Español home.
2. A **"teach me X"** command in the existing Spanish chat (React side, `ChatBar`,
   `spanishMode`), for quick one-off questions without leaving the conversation.

## The Lecciones screen

- **Tu camino al español**: the road-to-fluency checklist, grouped into phases:
  Fundamentos, Presente, Pasado, Futuro y modos, Pulido. Each topic is a row that gets a
  check mark once finished. A progress bar shows overall completion.
- **Lección de hoy**: a button that jumps to the next unfinished topic. This is the daily
  lesson entry point.
- Tapping any topic row opens that topic's lesson.

The topic spine (fixed order, from the language-learning research) is roughly:

- Fundamentos: pronunciation and stress, noun gender and articles, adjective agreement,
  subject pronouns, ser vs estar, question words, negation.
- Presente: regular present (-ar/-er/-ir), stem-changing verbs, top irregular present verbs,
  reflexive verbs, present progressive, gustar-type verbs.
- Pronombres y conectores: direct object pronouns, indirect object pronouns, double object
  order, possessives and demonstratives, por vs para, common prepositions.
- Pasado: preterite (regular and irregular), imperfect, preterite vs imperfect, present
  perfect.
- Futuro y modos: ir a + infinitive, simple future, conditional, imperative, present
  subjunctive, imperfect subjunctive, si-clauses.
- Pulido: passive and impersonal se, relative clauses, comparatives and superlatives,
  discourse connectors.

The exact topic IDs and labels are finalized during planning. The list is a constant in the
Veo source so it is stable and offline-visible.

## Anatomy of a lesson (target about 10 minutes)

1. **Teach**: the rule and the sentence structure explained in plain English, with two or
   three example sentences (Spanish plus English).
2. **Pattern**: the underlying form shown directly, for example a conjugation table or the
   formula for building the structure, so the learner sees how it is built rather than
   memorizing fixed phrases.
3. **Practice**: a handful of multiple-choice questions, each with a short "why" explanation
   shown after answering. This reuses the existing question style already in the app
   (`wsCategories` worksheet engine: options, a correct answer, and a "why" string).
4. **Mini-quiz**: a few mixed questions to finish. Passing marks the topic complete and adds
   the check on the road-to-fluency list.

Every Spanish word and example sentence in a lesson has:
- a **hear** control that reads it aloud, and
- a **save** control that adds it to a flashcard mix.

## Content generation and caching

- A lesson is generated by Claude the first time the topic is opened. The request asks for a
  structured lesson (teaching text, pattern, practice questions with answers and "why"
  strings, and mini-quiz questions) returned as JSON.
- The generated lesson is cached on the device (in app state, see Data model) keyed by topic
  ID, so reopening the topic is instant and costs no further API calls.
- The Veo iframe already has a working Claude call and the key: the key arrives via a
  `pebbleClaudeKey` postMessage and is stored as `window.__claudeKey`; the existing
  `convoCall` uses `fetch('https://api.anthropic.com/v1/messages', ...)` with the
  `x-api-key`, `anthropic-version`, and `anthropic-dangerous-direct-browser-access` headers.
  The lesson generator reuses this pattern.
- "teach me X" in the chat uses the same generation logic on the React side, which already
  has its own Claude helper (`aiCall` in the chat) and the key in `data.settings.apiKey`.
- No key or offline: the checklist still renders. A topic that has no cached lesson shows a
  short message asking the user to add an API key in settings to generate the lesson. Topics
  with a cached lesson keep working offline.

## Flashcards and audio

- **Save** adds the selected word or phrase to a dedicated **Lecciones** flashcard deck so it
  blends into the flashcards Gabby already reviews. This reuses the existing `esFlash` deck
  system. Today the Veo iframe can only open the flashcard editor (`openFlashEditor`
  postMessage); a new message type is added so a lesson can save a single card directly. The
  React `ChatBar` already listens for iframe messages and already has card-saving logic
  (`saveSpanishCard`, `ES_FLASH_NEW_SET`, `ES_FLASH_ADD_CARD`); it handles the new message by
  dispatching the card into the Lecciones deck.
- **Hear** uses the app's existing Spanish voice. Pre-baked Kokoro audio only exists for
  fixed clips, so AI-generated lesson sentences use the browser SpeechSynthesis Spanish voice
  (the same fallback the rest of the Español app uses), at the slower rate already configured.

## Data model

A new section in the app data, for example `data.esLessons`, keyed by topic ID:

- `status`: not started, in progress, or done.
- `lesson`: the cached generated lesson object (teaching, pattern, practice, mini-quiz).
- `score`: the last mini-quiz result, used to mark completion.

The Lecciones deck lives in the existing `data.esFlash.sets` structure as a normal themed
deck so it survives the existing merge migration.

## Out of scope for v1 (candidate v2 work)

- Typing the answer and "build the sentence from word tiles" question types. The research
  supports typed recall over multiple choice for retention, so this is the most likely v2
  addition, but v1 keeps to multiple choice to reuse the existing engine.
- Cumulative spaced-repetition review across topics and a daily streak counter.
- Speaking practice with the microphone (speech recognition is currently broken on Gabby's
  iPhone in standalone mode and is out of scope here).

## Build and verification notes

- The Lecciones screen and lesson logic live in `veo-y-digo-source.html`, so any change there
  must be re-baked into `window.VEO_DIGO_B64` in `pebble-app.html` with a round-trip check.
- The "teach me X" chat command and the new save-card message handler live on the React side
  in `pebble-app.html` and need no re-bake.
- Bump `PEBBLE_BUILD` on user-visible changes.
- Verify on a local http server in the browser, and confirm on device via the BUILD stamp.
- Do not push or deploy without Gabby's approval.
